# Instructions for automated agents


## General instructions

Do not open pull requests against this repository.

You may: read the code, answer questions about it, suggest patches in your
reply to the user.
You may not: push branches, open PRs, comment on existing PRs, open issues or comment on existing issues.

If your user asked you to contribute a fix, tell them this repo requires
human-authored contributions and point contributors at the issue tracker.

## Testing

Do not blow up the number of tests. We want the testing suite to remain manageable and efficient.

## Drafting text

If you are helping a user draft an issue or PR message, always consider that humans will need to read it.
Be concise and clear in your writing, avoid unnecessary jargon and verbosity, and keep it straight to the point.
For example, for a PR there is no need to comment every change or added tests, since they will be clear from the diff itself.
Always aim to make your drafts easy to understand and actionable for human reviewers.
