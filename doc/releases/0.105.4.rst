* Feat: expose ``periods`` property in silence_periods (#4897)
* Dredge fixes (#4889)
* Save ``dtype`` in ``phase_shift`` kwargs (#4886)
* Make motion-corrected and silenced recordings JSON-serializable (#4877)

extractors:

* Fix: openephys - check ``sync_times`` only if not None (#4890)

sorters:

* Add ``main_channel_id`` to Lupin (#4894)
