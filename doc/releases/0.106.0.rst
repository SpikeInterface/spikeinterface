SpikeInterface 0.106.0 release notes
------------------------------------

Nov 13th 2026

Main changes:

* Added support for Zarr v3, with zarr shards computed one chunk at a time and waveforms extracted directly to Zarr datasets (#4260, #4907, #4708)
* Added session displacement generation to the generators and motion correction modules (#3231)
* Added the ``VanillaSort`` external sorter and the ``NeuroExplorerSortingExtractor`` (#4832, #4825)
* Added support for Python 3.14 (#4173)
* Removed the ``BaseSnippets`` class (#4839)
* Reduced peak memory usage in several preprocessors (``gaussian_filter``, filters) and in extensions through ``SpikeRetriever`` and ``UnitSelectionSorting`` optimizations (#4903, #4840, #4809, #4783)
* Significant speedups in template similarity (#4785), amplitude scalings (#4870), phase shift and ``gaussian_filter`` FFTs (#4802, #4853), and Wobble peak search (#4782)

core:

* Remove duplicated ``get_recording_property`` and ``get_sorting_property`` (#4933)
* Fix binary save when only some segments have a time vector (#4923)
* Fix saving a recording when only some segments have a ``t_start`` (#4922)
* Fix ``select_periods`` dropping metadata, recording, times and empty segments (#4921)
* Compute zarr shards one chunk at a time to reduce peak memory (#4907)
* Remove legacy location property when loading old recordings (#4896)
* Fix: do not include extra_metadata in zarr provenance dump (#4885)
* Store pickled extension data in zarr SortingAnalyzers as byte arrays instead of object arrays (#4882)
* Store JSON data in zarr SortingAnalyzers as byte arrays instead of object arrays (#4881)
* Make motion-corrected and silenced recordings JSON-serializable (#4877)
* Add a SortingAnalyzer fixture to the cross-version serialization tests (#4876)
* Read zarr v2 NWB files with zarr-python 3 (#4875)
* Allow for ``main_channel_indices`` to use rec attributes (#4867)
* Reintroduce ``set_times(..., with_warning)``, with deprecation (#4864)
* Fix: channel_slice should not check overlapping probes (#4862)
* Override search_cached_spikes_sorted for identity selections (#4845)
* Remove ``BaseSnippets`` class (#4839)
* Fix group (and other property) propagation in channel slice (#4838)
* Fix: remove ``set_times`` warning (#4834)
* Run the tests with ``forkserver`` on Linux (#4818)
* Rename the spike vector caches to state which order they hold (#4817)
* Enable case omission  on ``get_unit_spike_train_in_seconds`` (#4811)
* Optimize ``SpikeRetriever`` and RAM usage for extensions (#4809)
* Fix: provenance handling in ``SortingAnalyzer`` (#4805)
* Fix: drop new_unit_ids of non-mergeable units (#4804)
* Fix: zarr pickling in ``SortingAnalyzer`` with ``try``/``except`` (#4801)
* Fix: make seed JSON serializable (#4798)
* Fix sorting times segment propagation (#4796)
* UnitSelectionSorting improvements: remove lexsort, fix bug, save memory by sharing parent cache when possible (#4783)
* Extract waveforms to zarr dataset (#4708)
* Support zarr v3 (#4260)
